TOPIC
    about_SendGridTools

SHORT DESCRIPTION
    Manage SendGrid from PowerShell through the SendGrid v3 Web API.

LONG DESCRIPTION
    SendGridTools is a PowerShell module that wraps the SendGrid v3 Web
    API. It covers these areas:

      - Mail: send messages (Send-SGMailMessage) and read email
        activity (Get-SGEmailActivity).
      - Suppressions: suppression groups, group members and global
        suppressions.
      - Bounces, blocks, spam reports and invalid emails: list and
        remove entries.
      - Authenticated domains and branded (link branding) domains:
        create, verify, change and remove.
      - Subusers: create, enable, disable and remove.
      - API keys: list, create, change and remove.
      - Alerts: create, change and remove.
      - Settings: mail, bounce purge, forward bounce, forward spam and
        address allow list settings.
      - Teammates (Get-SGTeammate), IP addresses (Get-SGIPAddress),
        designs (Get-SGDesign) and permission scopes
        (Get-SGPermissionScopes): read what the account holds.
      - Invoke-SGCommand: call an endpoint the module has no command
        for.

    To list every command, run:

        Get-Command -Module SendGridTools

    SIGNING IN
    Every session starts with Connect-SendGrid. It takes a PSCredential
    object where the Password field holds the SendGrid API key; the
    user name is not used. Connect-SendGrid -Force replaces an existing
    session. Disconnect-SendGrid ends the session.

    SESSION LIFETIME
    A session lasts one hour. Each command that completes a request
    renews the hour. When the hour passes without use, the next command
    fails with an error that the session has expired; run
    Connect-SendGrid -Force. A plain Connect-SendGrid fails the first
    time, because it tries to refresh the expired session.

EXAMPLES
    Example 1: Sign in

    PS C:\> $Credential = Get-Credential
    PS C:\> Connect-SendGrid -Credential $Credential

    Enter any user name and the API key as the password.

    Example 2: List authenticated domains with their DNS records

    PS C:\> Get-SGAuthenticatedDomain -ShowDNS

    Example 3: Send a message

    PS C:\> $Message = @{
        From    = '<address>'
        To      = '<address>'
        Subject = '<subject>'
        Body    = '<text>'
    }
    PS C:\> Send-SGMailMessage @Message

    If a command fails with an error that the session has expired, run
    Connect-SendGrid -Force.
